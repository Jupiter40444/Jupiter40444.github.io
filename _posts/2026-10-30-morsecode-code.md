For this project I had to create code that would cause an off board vibe board to buzz either my name or SOS in morse code depending on the state of a button. I wrote functions for long and short buzzes, the wrote functions 
for each required letter. Finally, I called these functions with conditionals based on the button. I actually struggled most with getting my button to work, which had been difficult for me in the past. I wish I had gone back and
referenced the code for our buttons given to us in the Moodle earlier to help me with the button component of the project.
