For this coding project I had to combine three different pieces of code for the blue ghost, flash bulb, and Big Dipper firefly patterns. Integrating the code was very simple. All I had to 
do was copy and paste the code in to one big file, delete redundancies, and make sure it ran all together. Coding the pieces on their own was a bit challenging though. They all involved some 
sort of timer based activation of the bulb, usually requiring a state variable/boolean, and for the instances where the bulb was getting gradually brighter, it required fade time and amount variables. 
I would advise anyone attempting this code to be very careful and intentional about naming their variables.
