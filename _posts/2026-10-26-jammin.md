For this project we had to find code online that would play a song on our Arduino's buzzer. I chose the pink panther theme song which I found on an Arduino Project Hub message board. The code was 
created by tmekinyan on Github. The code was already written to play in void loop, so I didn't have to change anything to make the song play in a loop rather than only once. I had a a lot of trouble 
getting my button to work. I couldn't get it to work with the practice code Arduino gives you that lights up an LED, however, the syntax of my code should be more or less correct for what I was trying to 
achieve with the button. I set it up with an if statement so that if that the button value read as high then the song would play and else, it wouldn't. A tip I would give myself is to space out the code
into smaller chunks before integrating the button code with the borrowed code.
