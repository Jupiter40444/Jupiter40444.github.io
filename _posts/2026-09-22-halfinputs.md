For this project we had to design code that would store a variable button and switch and turn on lights depending on the conditions of said variables. If button was false and switch was false LED1 would blink, if button was false and switch was true, LED2 would blink, and so on and so forth up until LED4 (as there are only 4 possible combinations of true and false). We had the option to program with logical operators
or nested conditionals. Personally, I chose to use booleans because nested conditionals are useful if you want to execute a piece of code only if the an initial conditional is true. Because only one light was to be 
on at a time, and we had four separate lights with different conditions causing their on or off status, I didn't think nested conditionals would be particularly useful. A tip I would give to my past self is to 
reference the worksheet from class right away, because it contained code that could be almost exactly copied for this particular problem.
